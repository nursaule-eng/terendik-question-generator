# Тереңдік

Учебное приложение: PDF/TXT → темы → генерация вопросов → AI-проверка → решение преподавателя → тест и сохранённый результат.

FastAPI, SQLite, PyMuPDF, TF-IDF и OpenAI-совместимый Chat Completions API. Генерация поддерживает казахский, русский и английский, пять запрашиваемых уровней, тестовые и открытые вопросы. Приложение отмечает повторы и расхождения сложности; вопросы допускаются к тесту после ручного принятия.

## Запуск

Python 3.11–3.13. В корне проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Вставьте свой API-ключ в `.env` и укажите URL и модель. Для Gemini есть отдельный шаблон `.env.gemini.example`; скопируйте его содержимое в локальный `.env`, если хотите использовать этого провайдера. Не публикуйте ключи.

```powershell
.\.venv\Scripts\python.exe -m app.check_model
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000/. Этот адрес работает только на компьютере, где запущен сервер. Интерактивная документация API — `/docs`.

На macOS/Linux используйте `python3 -m venv .venv` и `.venv/bin/python` вместо пути Windows.

## Работа

1. Загрузите PDF с текстовым слоем или TXT размером до 20 МБ. Дождитесь анализа тем.
2. Выберите язык, тему, уровень, количество и тип вопросов; запустите генерацию.
3. В банке проверьте ответ, цитату, сложность и замечания AI; примите качественные вопросы. После редактирования нужна повторная AI-проверка.
4. Создайте и завершите тест. MCQ проверяет сервер, открытые ответы сохраняются с эталоном для субъективной самооценки.

Документы, вопросы и попытки хранятся локально в `data/`. Они не включены в репозиторий. При первом запуске создаётся пустая база. Снимки вопросов в завершённых попытках сохраняются независимо от дальнейших правок банка.

Новый интерфейс расположен в `app/static/index.html`, его код — в `app/static/app.js`, стили — в `app/static/redesign.css`. Предыдущая версия сохранена как `index_old.html` и `app_old.js`.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
```

Тесты используют отдельные временные данные и подмену модели; они не требуют действующего API-ключа. Реальный сервис может ограничивать запросы или быть недоступен. Размеченные примеры повторов и синтетический материал в `tests/` предназначены для технической проверки.

## Доступ для других людей

Этот репозиторий содержит исходники, а не опубликованное работающее приложение. GitHub Pages раздаёт статические файлы и не запускает FastAPI, SQLite и генерацию через серверный API. Для общей рабочей ссылки нужен Python-хостинг с постоянным хранилищем и серверными переменными окружения.

Текущая версия рассчитана на локальный учебный прототип: нет авторизации и разграничения ролей, банк содержит ответы, есть операции удаления. До публичного размещения необходимо защитить доступ преподавателя и адаптировать проверку разрешённых имён хоста. Секрет API задаётся только на сервере; его нельзя вставлять в HTML/JavaScript или коммиты. Локальные файлы пользователя и база на хостинг автоматически не переносятся.

## Ограничения

AI может ошибаться в правильности ответов, сложности и поиске смысловых повторов. Цитата подтверждает происхождение текста, но не гарантирует верность вычислений. Уровень, запрошенный при генерации, и уровень рецензента могут различаться. Сложные MCQ проходят дополнительное независимое решение, однако ручная проверка остаётся необходимой. Для сканов нет OCR. Прерванные фоновые задания после перезапуска не продолжаются автоматически.
