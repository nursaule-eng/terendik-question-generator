# Тереңдік

Размещённая демонстрация: **[Открыть Тереңдік](https://terendik-question-generator.onrender.com/)**. Для входа нужен пароль от владельца. Gemini API-ключ хранится на сервере и посетителям не выдаётся. Без переменной `DATABASE_URL` бесплатный Render хранит данные на временном диске; с ней (PostgreSQL, например Neon) материалы, вопросы и результаты сохраняются постоянно — см. раздел о размещении.

Учебное приложение: PDF/DOCX/TXT → темы → генерация вопросов пяти уровней → AI-проверка → решение преподавателя → тест для студентов по ссылке → AI-оценка открытых ответов → статистика знаний.

FastAPI, SQLite (локально) или PostgreSQL (хостинг), PyMuPDF, python-docx, TF-IDF (словные + символьные n-граммы) и OpenAI-совместимый Chat Completions API. Генерация и интерфейс студента работают на казахском, русском и английском.

## Что умеет

- **Материалы:** PDF с текстовым слоем, DOCX, TXT (UTF-8, cp1251, KZ-1048). PDF, набранные старыми казахскими шрифтами (KZ Times и т. п.), где «қ» извлекается как «ќ», исправляются автоматически, и преподаватель видит предупреждение. Язык (kk/ru/en, включая казахскую латиницу) определяется по доле букв, а не по одной букве.
- **Генерация:** очередь в базе данных. Каждый вопрос сохраняется сразу. При лимите модели (HTTP 429) генерация ждёт и продолжается сама; при дневном лимите встаёт на паузу с кнопкой «Продолжить». Её можно остановить. После перезапуска или «засыпания» сервера она продолжается с того же места. Перед запуском показывается, хватит ли материала на запрошенное количество.
- **Качество:** проверка цитаты в источнике, независимый AI-рецензент, независимое решение тестовых и расчётных открытых вопросов (уровни 3–5), **программная проверка вычислений**: решатель возвращает арифметическое выражение, сервер вычисляет его безопасным разбором AST и сверяет с числом в правильном ответе. Если рецензент определил другой уровень, вопрос один раз дорабатывается под нужный. Уровень 5 в смешанной генерации — открытые задачи на построение решения.
- **Роли:** преподаватель входит по паролю. Студент получает ссылку `/s/<код>`, вводит имя и проходит тест. Банк, ответы до завершения и другие попытки ему недоступны. Ответы-черновики сохраняются на устройстве студента. Интерфейс студента — қазақша / русский / English.
- **Оценивание:** тестовые проверяет сервер, открытые оценивает ИИ (0–10, что хорошо, что упущено, что повторить). Можно показывать студентам правильные ответы или только баллы, а также закрыть приём ответов.
- **Итоги:** результаты по каждой ссылке (с выгрузкой в CSV), статистика по темам и уровням, слабые темы, студенты, динамика.
- **Экспорт:** принятые вопросы в Word (с ответами или для студентов), CSV для Excel, JSON. **Резервная копия** всех данных в JSON и восстановление из неё.

## Запуск

Python 3.11–3.13. В корне проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Вставьте свой API-ключ в `.env` и укажите URL и модель. Без `DATABASE_URL` используется SQLite в `data/`. Для Gemini есть отдельный шаблон `.env.gemini.example`; скопируйте его содержимое в локальный `.env`, если хотите использовать этого провайдера. Не публикуйте ключи.

```powershell
.\.venv\Scripts\python.exe -m app.check_model
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000/. Этот адрес работает только на компьютере, где запущен сервер. Интерактивная документация API — `/docs`.

На macOS/Linux используйте `python3 -m venv .venv` и `.venv/bin/python` вместо пути Windows.

## Работа

1. Загрузите PDF с текстовым слоем, DOCX или TXT размером до 20 МБ. Дождитесь анализа тем.
2. «Генерация»: выберите уровень, тему, количество, тип и язык; запустите. Вкладку можно закрыть.
3. «Банк»: проверьте ответ, цитату, сложность и замечания AI; примите качественные вопросы. После редактирования нужна повторная AI-проверка. Отсюда же выгрузка в Word/CSV/JSON.
4. «Тест»: пробная попытка преподавателя.
5. «Студенты»: создайте ссылку, отправьте её группе, смотрите результаты и статистику.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
```

Тесты используют отдельные временные данные и подмену модели; они не требуют действующего API-ключа. Чтобы прогнать те же тесты на PostgreSQL, задайте `TEST_DATABASE_URL` (база будет очищаться перед каждым тестом). Реальный сервис может ограничивать запросы или быть недоступен. Размеченные примеры повторов и синтетический материал в `tests/` предназначены для технической проверки.

## Размещение на Render с постоянными данными

Бесплатный Render использует временный диск: без внешней базы всё пропадает при пересоздании сервиса. Решение — бесплатная PostgreSQL-база, например Neon:

1. Создайте проект на neon.tech и скопируйте строку подключения (`postgresql://…?sslmode=require`). Подходит и адрес с `-pooler`.
2. В Render → сервис → Environment добавьте `DATABASE_URL` с этой строкой и сохраните. Таблицы создаются автоматически при запуске.
3. Если в старой версии были данные: до переключения скачайте «Резервную копию» в левой панели, после — загрузите её через «Восстановить из копии».

После этого в левой панели вместо предупреждения появится «Данные хранятся в базе PostgreSQL».

Команда запуска: `uvicorn app.deployment:create_app --factory --host 0.0.0.0 --port $PORT --proxy-headers --forwarded-allow-ips '*'`. Секреты: `APP_ACCESS_PASSWORD` (пароль преподавателя, от 20 символов), `LLM_API_KEY`, `DATABASE_URL`. Студентам пароль не нужен: открыты только `/s/<код>` и `/api/s/<код>`, всё остальное API требует входа преподавателя. Сессия преподавателя действует 7 дней; выход — ссылка «Выйти».

Бесплатный сервер засыпает без посещений. Если это случилось во время генерации, после пробуждения она продолжится автоматически.

## Ограничения

AI может ошибаться в правильности ответов, сложности и поиске смысловых повторов. Цитата подтверждает происхождение текста, но не гарантирует верность вычислений. Уровень, запрошенный при генерации, и уровень рецензента могут различаться. Сложные MCQ проходят дополнительное независимое решение, однако ручная проверка остаётся необходимой. Программная проверка вычислений срабатывает, когда ответ — одно число; остальные расчёты проверяет только независимое решение модели. AI-оценка открытых ответов — ориентир, итоговую оценку ставит преподаватель. Оценка «хватит ли материала» приблизительная. Для сканов нет OCR, файлы .doc нужно сохранить как .docx.
